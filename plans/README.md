# plan-floor1 / plan-floor2：一楼与二楼

来源：`~/Downloads/设计图.pdf`（扫描 PDF，2025 年 11 月图纸）。
- 一楼：PDF 第 7 页，JS-04，1:100；原图建筑面积 138.40 m²。
- 二楼：PDF 第 8 页，JS-05，1:100；原图建筑面积 114.06 m²。

## 导入

使用本次更新后的 `index.html`，打开「文件 ▾ → 导入方案」，选择本目录的 `plan-floor1.json` 或 `plan-floor2.json`。
页面右上角「方案」列表可直接切换一楼、二楼。导入 JSON 会新增方案并切换到该方案；同名文件使用编号区分，保留已有版本。切换前自动保存当前布置，各方案编辑历史独立（刷新后撤销历史清空），方案列表和当前方案自动保存在浏览器本地。可通过导出 JSON 备份当前方案。
两层为独立方案，不是同时叠加的楼栋模型。旧版页面不支持 JSON 中的 `geometry`，必须使用本次更新后的页面。

## 重建精度

坐标为毫米，原点为 1/A 轴线交点，x 向右、y 向下。
横向轴线为 0、4000、8000、12000 mm。
一楼左侧纵向标注为 3900、1600、4000、1500、800 mm；二楼为 3900、1600、3000、2500、800 mm，总长均为 11800 mm。
右侧共同标注为 3000、2500、5500、800 mm。

图纸未逐一标出墙厚、洞口尺寸和家具尺寸，这些按扫描图估算；采用 200 mm 墙厚，内外墙按轴线及图示重建。家具采用项目现有模型。
一楼上中房原图文字为“卧室”，图示却为圆餐桌，命名为“卧室（图示餐桌）”，不替原图改用途。
二楼的右上屋顶放大示意不作为房间导入。书房未臆造家具。
地面材料为显示默认值，不能作为施工或材料采购依据。

未判断承重结构；内部墙体类型 `n` 只是编辑器分类，不代表实际可以拆除。
楼梯为两跑示意模型，不含楼板洞口、平台扶手或上下楼漫游；3D 墙高/楼梯高度沿用项目 2.8 m 的展示尺度，未按一楼至二楼 4.100 m 的标高差建模。
一楼门廊前缘保持开放，不生成围栏；二楼露台栏杆用矮墙表示。旧版一楼方案在导入或恢复时自动移除误加的前缘矮墙，保留其他编辑。每层独立显示，不含屋顶和层间连接。

项目平面净面积按房间多边形求和，包含门廊/露台，不能与图纸建筑面积直接比较。
当前估算：一楼 125.30 m²，二楼 124.74 m²（含露台约 24.18 m²）。

## JSON 结构

`furniture`、`rooms`、`demolished`、`measures` 沿用原方案格式。
新增 `format: "floorplan-3d"`、`version: 2`、`metadata`（来源及精度说明）和 `geometry`：

| 字段 | 结构 |
| --- | --- |
| `walls` | `[x0,y0,x1,y1,type]`；`e` 外墙，`n` 内墙，`low` 矮墙，`b` 承重墙 |
| `windows` | 窗洞矩形 `[x0,y0,x1,y1]` |
| `doors` | `{name,rect,h,c,o,len,entry?}`；`h` 铰点，`c/o` 关闭/开启单位方向向量 |
| `slides` | 推拉门 `{rect,v}`，本方案为空 |
| `rooms` | `{id,name,poly,mat,at,outdoor?}`；`poly` 多边形，`at` 标签位置 |
| `stairs` | `{rect,steps,reverse,baseHeight,height}`；高度单位米，其余位置单位毫米 |
| `dimensions` | `{horizontal,at,start,segments}`，尺寸链 |
| `walkStart` | `{position,target}`，漫游初始位置与朝向 |

门窗洞口与实墙分段分开存储；窗洞由渲染器补窗台及过梁。`outdoor` 房间无天花。
未包含 `geometry` 的旧 JSON 仍恢复项目原始户型；「重置为默认方案」也恢复原始户型。

手工标定重建脚本：`python3 scripts/build_floor_plans.py`。
导入验证：`node scripts/test_plan_import.cjs`。
